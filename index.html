artd-binary-diff-tool

The Roll Comparison. Compares two binary files and reports the differences in their disassembled code, for vulnerability analysis and patch diffing.

The repository main.py
Parses withLIEF, for the binary structure
Disassembles withCapstone, over the executable sections
ReportsAdded, removed, and modified instructions, keyed by address
LicenceMIT License, see LICENSE in the repository

Usage

python3 main.py FILE1 FILE2 [-a ARCH] [-o OUTPUT] [-v]
ParameterWhat it does
FILE1The first binary file to compare.
FILE2The second binary file to compare.
-a, --architectureArchitecture of the binary files: x86 (default), x64, arm, or arm64.
-o, --outputOutput file to save the diff results. If not provided, the diff prints to console.
-v, --verboseEnable verbose logging.
-hShow help message and exit.

Stated limits

  • The diff is keyed on absolute addresses with no alignment of the two instruction streams, so one inserted instruction early in a function can read as many added and removed instructions rather than one modified spot.
  • A missing input file, or a path that is not a file, exits 1.
  • A live run was not possible in the documenting environment: the lief and capstone packages are not installed there. The parameter list is taken from the argument parser in main.py, and the file compiles cleanly.
